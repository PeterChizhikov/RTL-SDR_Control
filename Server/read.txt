TCP команды от клиента разделяются на 2 типа: "system" и "settings":

TCP_PORT_SERVER = 5577

system - отвечает за начало и остановку передачи данных на клиент с примемника
{
    "type": "system"
    "action": "start"
}
or
{
    "type": "system"
    "action": "stop"
}

settings - отвечает за установку нужных параметров на примемник 
sample rate, center frequency, frequency correction(PPM), gain.
Усиление нужно предложить пользователю ввести самому,
либо выставить на авто
{
    "type": "settings"
    "sample_rate": ""
    "center_frequency": ""
    "frequency_correction": ""
    "gain": ""
}
