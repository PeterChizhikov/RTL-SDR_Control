TCP команды от клиента разделяются на 2 типа: "system" и "settings":

TCP_PORT_SERVER = 5577
-------------------------------------1 тип-----------------------------------
system - отвечает за начало и остановку передачи данных на клиент с примемника
{
    "type": "system"
    "action": "start"
}
or
{
    "type": "system"
    "action": "stop"
}
Ответ:
вариант успешного старта работы приемника:
{
    "answer": 200 (int16)
}
вариант, когда  приемник не начнет работать, применика нет или он заблокирован
{
    "answer": 423 (int16)
}
-------------------------------------2 тип------------------------------------
settings - отвечает за установку нужных параметров на примемник 
sample rate, center frequency, frequency correction(PPM), gain.
Усиление нужно предложить пользователю ввести самому,
либо выставить на авто
{
    "type": "settings"
    "sample_rate": ""  (int64)
    "center_frequency": "" (int64)
    "frequency_correction": "" 
    "gain": "" ("auto", || (int32))
}
Ответы от сервера:
вариант успешной установки параметров:
{
    "answer": 200 (int16)
}
вариант неуспешной, конфликт настроек:
{
    "answer": 409 (int16)
}
